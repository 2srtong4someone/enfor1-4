# Engkids — английский с Лео

Интерактивный адаптивный сайт для занятий английским с детьми 1–4 классов. В демо-уроке можно послушать слово, выбрать его перевод и потренировать устную речь. В домашней работе есть пять заданий для каждого класса: вопросы и варианты ответов показаны на английском и русском, а после проверки ученик получает оценку по пятибалльной шкале и объяснения к каждому ответу. Выбранный класс, заработанные звёзды и результаты домашней работы сохраняются в браузере.

Главная страница: `templates/index.html`. Стили: `static/css/style.css`. Интерактивность: `static/js/app.js`. Flask обслуживает страницу и файлы сайта.

## Запуск

Требуется Python 3.9 или новее.

```bash
cd enfor1-4
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:5000` в браузере. Озвучивание и распознавание речи зависят от поддержки браузера и интернет-соединения. Если Safari прерывает прослушивание, сайт автоматически попробует подключить микрофон снова; разрешите доступ к микрофону для сайта в настройках Safari. Устное задание также можно выполнить без автоматического распознавания кнопкой «Я сказал».

## Публикация в интернете

Для постоянной публичной ссылки можно развернуть сайт на Render:

1. Создайте GitHub-репозиторий и загрузите в него файлы проекта, кроме `.venv`.
2. Создайте аккаунт на [Render](https://render.com/) и подключите GitHub.
3. В Render выберите **New → Blueprint**, укажите репозиторий и подтвердите создание сервиса по `render.yaml`.
4. После успешного развёртывания Render покажет публичный адрес сайта.

Бесплатный веб-сервис Render может переходить в спящий режим после периода бездействия; первый запрос после этого может загружаться дольше.
